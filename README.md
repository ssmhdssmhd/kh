# 工作助手应用

## 项目简介

工作助手是一个专为职场人士设计的桌面应用程序，用于自动记录和管理会议要点、工作内容、工作细节以及改进建议。该应用提供了直观的图形界面和强大的会议提醒功能，帮助用户高效管理日常工作。

## 功能特性

### 1. 会议要点记录 📋
- 记录会议主题、时间、参会人员
- 详细记录会议要点内容
- 自动保存时间戳
- 支持历史会议记录查看
- 单击记录查看详情
- 双击记录可删除

### 2. 工作内容记录 📝
- 记录工作主题和日期
- 详细描述工作内容
- 按日期排序显示
- 内容预览功能
- 支持详情查看和删除

### 3. 工作细节记录 🔍
- 记录具体工作细节
- 时间戳自动生成
- 详细内容编辑区
- 历史细节回顾

### 4. 改进建议记录 💡
- 记录改进主题和内容
- 状态管理（待处理/进行中/已完成）
- 跟踪改进进度
- 状态可视化显示

### 5. 会议提醒 ⏰
- 设置会议提醒时间
- 自定义提前提醒时间（5分钟/10分钟/15分钟/30分钟/1小时）
- 自动后台检测
- 弹窗提醒通知
- 提醒状态管理

## 安装与使用

### 方法一：直接运行（推荐）

1. 确保已安装 Python 3
```bash
python3 --version
```

2. 运行应用
```bash
python3 work_assistant.py
```

### 方法二：打包为 macOS 应用

1. 运行打包脚本
```bash
chmod +x build_app.sh
./build_app.sh
```

2. 双击生成的 `工作助手.app` 即可运行

### 方法三：打包为 ZIP 文件

1. 运行打包脚本
```bash
chmod +x build_zip.sh
./build_zip.sh
```

2. 解压生成的 ZIP 文件，运行其中的 `work_assistant.py`

## 使用指南

### 会议记录流程
1. 点击"📋 会议要点"标签页
2. 输入会议主题、时间、参会人员
3. 在文本框中详细记录会议要点
4. 点击"保存记录"按钮
5. 查看历史记录列表，单击查看详情

### 工作记录流程
1. 点击"📝 工作内容"标签页
2. 输入工作主题和日期
3. 详细描述工作内容
4. 点击"保存记录"按钮

### 设置会议提醒
1. 点击"⏰ 会议提醒"标签页
2. 输入会议主题和时间（格式：YYYY-MM-DD HH:MM）
3. 选择提前提醒时间
4. 点击"添加提醒"按钮
5. 应用会在设定时间自动弹窗提醒

### 查看记录详情
- 在任一记录列表中，单击记录项即可打开详情窗口
- 双击记录项可删除该记录（需确认）

## 注意事项

1. **数据存储**: 所有数据保存在应用目录的 `data/` 文件夹中，请勿随意删除
2. **时间格式**: 会议提醒时间格式必须为 `YYYY-MM-DD HH:MM`
3. **提醒功能**: 应用需保持运行状态才能触发提醒
4. **数据备份**: 建议定期备份 `data/` 目录中的文件
