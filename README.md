# 工作助手应用

## 项目简介

工作助手是一个专为职场人士设计的智能会议记录应用程序，具备**语音自动识别**和**智能总结**功能。应用能够自动听会议中的说话内容，实时转换为文字，并自动生成会议总结、提取关键词和行动项，全程无需人工干预。

## 功能特性

### 1. 智能会议录音 🎤
- **语音自动转文字**: 使用麦克风实时录制会议语音，自动转换为文字
- **实时显示**: 每段语音识别完成后立即显示，带有时间戳
- **无需人工干预**: 全程自动记录，无需手动输入
- **中文支持**: 完美支持中文语音识别

### 2. 自动智能总结 🤖
- **自动生成总结**: 根据语音转文字内容，自动生成会议总结
- **实时更新**: 录音过程中持续更新总结内容
- **重点突出**: 提取最重要的5个核心句子

### 3. 关键词提取 🔑
- **自动识别关键词**: 从会议内容中自动提取高频重要词汇
- **智能过滤**: 排除常用虚词，保留真正有意义的关键词
- **可视化展示**: 以标签形式展示关键词

### 4. 行动项提取 ✅
- **自动识别任务**: 通过关键词模式匹配，自动识别会议中的行动项
- **任务分类**: 识别"需要做"、"负责"、"时间"、"下一步"等行动指令
- **清单展示**: 以编号清单形式展示所有行动项

### 5. 工作内容记录 📝
- 记录工作主题和日期
- 详细描述工作内容
- 按日期排序显示
- 内容预览功能
- 支持详情查看和删除

### 6. 工作细节记录 🔍
- 记录具体工作细节
- 时间戳自动生成
- 详细内容编辑区
- 历史细节回顾

### 7. 改进建议记录 💡
- 记录改进主题和内容
- 状态管理（待处理/进行中/已完成）
- 跟踪改进进度
- 状态可视化显示

### 8. 会议提醒 ⏰
- 设置会议提醒时间
- 自定义提前提醒时间（5分钟/10分钟/15分钟/30分钟/1小时）
- 自动后台检测
- 弹窗提醒通知
- 提醒状态管理

## 系统要求

- Python 3.6 或更高版本
- Tkinter（Python标准库）
- **语音识别依赖**:
  - `SpeechRecognition` - 语音识别库

  - Windows 7/8/10/11

  - Linux（主流发行版）
- 硬件要求：麦克风设备

## 安装与使用

### 方法一：直接运行（推荐）

1. 确保已安装 Python 3
```bash
python3 --version
```

2. 安装语音识别依赖
```bash
# 安装基础依赖
pip install SpeechRecognition

# macOS/Linux 安装音频库
pip install pyaudio

# 可选：安装自然语言处理库（提升总结效果）
pip install nltk
```

3. 运行应用
```bash
python3 work_assistant.py
```

### 方法二：打包为 macOS 应用

1. 运行打包脚本
```bash
chmod +x build_app.sh
./build_app.sh
```

2. 双击生成的 `工作助手.app` 即可运行

### 方法三：打包为 ZIP 文件

1. 运行打包脚本
```bash
chmod +x build_zip.sh
./build_zip.sh
```

2. 解压生成的 ZIP 文件，运行其中的 `work_assistant.py`

## 使用指南

### 智能会议录音流程（推荐）
1. 点击"🎤 会议录音"标签页
2. **点击"开始录音"按钮** - 应用会自动开始监听麦克风
3. **说话** - 会议内容会实时转换为文字显示在左侧面板
4. **自动总结** - 右侧面板会自动生成总结、关键词和行动项
5. **点击"停止录音"** - 录音结束，总结已自动生成
6. 填写会议主题、时间、参会人员（可选）
7. 点击"保存记录"按钮 - 完整保存录音内容和总结

### 工作记录流程
1. 点击"📝 工作内容"标签页
2. 输入工作主题和日期
3. 详细描述工作内容
4. 点击"保存记录"按钮

### 设置会议提醒
1. 点击"⏰ 会议提醒"标签页
2. 输入会议主题和时间（格式：YYYY-MM-DD HH:MM）
3. 选择提前提醒时间
4. 点击"添加提醒"按钮
5. 应用会在设定时间自动弹窗提醒

### 查看记录详情
- 在任一记录列表中，单击记录项即可打开详情窗口
- 双击记录项可删除该记录（需确认）
- 会议记录详情包含"完整记录"和"总结"两个标签页

## 注意事项

1. **数据存储**: 所有数据保存在应用目录的 `data/` 文件夹中，请勿随意删除
2. **时间格式**: 会议提醒时间格式必须为 `YYYY-MM-DD HH:MM`
3. **提醒功能**: 应用需保持运行状态才能触发提醒
4. **数据备份**: 建议定期备份 `data/` 目录中的文件
5. **语音识别**: 需要安装 `SpeechRecognition` 和 `pyaudio` 库，确保麦克风正常工作
6. **网络要求**: 语音识别需要联网（使用Google云端API）
7. **录音环境**: 建议在安静环境下使用，提高识别准确率
8. **麦克风权限**: 首次使用需要授予麦克风权限
