# 工作助手应用

## 项目简介

工作助手是一个专为职场人士设计的**专业级智能会议记录应用**，具备**实时语音识别**、**自动文字纠错**、**智能字幕显示**和**AI智能总结**功能。应用能够自动听会议中的说话内容，实时转换为精准文字，自动纠错和添加标点，并生成美观的会议记录和智能分析报告，全程无需人工干预。

**支持平台**:
- 🖥️ Windows / macOS / Linux（桌面版本）
- 📱 Android（移动版本）

## 功能特性

### 1. 专业开会模式 🎯
- **沉浸式会议体验**: 专门为会议场景设计的界面，减少干扰
- **实时字幕显示**: 像电视字幕一样，实时显示说话内容，大字清晰
- **会议计时器**: 精确记录会议时长，实时显示
- **三栏布局**: 完整记录、实时字幕、智能分析，一目了然
- **一键开始**: 点击按钮即可开始录音，自动记录一切

### 2. 实时语音识别 🎤
- **实时转文字**: 说话即转文字，无需等待
- **中文精准识别**: 优化中文语音识别，准确率高
- **时间戳记录**: 每句话都带时间戳，方便回溯
- **低延迟响应**: 边说边转，几乎同步

### 3. 文字自动纠错 ✨
- **智能纠错**: 自动修正语音识别常见错误
- **重复词过滤**: 去除"然后然后"、"就是就是"等重复词
- **语气词优化**: 智能处理"嗯"、"啊"、"这个"等填充词
- **错字修正**: 自动修正同音错字和常见识别错误

### 4. 自动标点符号 📝
- **智能加标点**: 根据语义自动添加逗号、句号、问号
- **断句优化**: 自动划分句子，阅读更流畅
- **语气识别**: 根据语气词智能添加感叹号、问号
- **格式规范**: 统一标点格式，美观规范

### 5. 智能实时字幕 🎬
- **大字显示**: 18号粗体字，清晰易读
- **深色背景**: 深色背景配白色文字，保护眼睛
- **滚动显示**: 最新内容在底部，自动上滚
- **多行显示**: 显示最近5行，上下文完整

### 6. AI智能总结 🤖
- **自动生成总结**: 根据会议内容自动生成核心总结
- **关键词提取**: 智能提取10-15个核心关键词
- **行动项识别**: 自动识别"需要做"、"负责"、"下一步"等行动项
- **实时更新**: 录音过程中持续更新分析结果

### 7. 美观专业界面 🎨
- **现代化设计**: 简洁大气的界面风格
- **三栏布局**: 完整记录、实时字幕、智能分析并列显示
- **配色专业**: 蓝色主色调，专业商务风格
- **响应式布局**: 窗口可自由调整大小

### 8. 工作内容记录 📝

- 详细描述工作内容

- 内容预览功能

## 安装与使用

### 方法一：直接运行（推荐）

1. 确保已安装 Python 3
```bash
python3 --version
```

2. 安装语音识别依赖
```bash
# 安装基础依赖
pip install SpeechRecognition

# macOS/Linux 安装音频库
pip install pyaudio

# 可选：安装自然语言处理库（提升总结效果）
pip install nltk
```

3. 运行应用
```bash
python3 work_assistant.py
```

### 方法二：打包为 macOS 应用

1. 运行打包脚本
```bash
chmod +x build_app.sh
./build_app.sh
```

2. 双击生成的 `工作助手.app` 即可运行

### 方法三：打包为 ZIP 文件

1. 运行打包脚本
```bash
chmod +x build_zip.sh
./build_zip.sh
```

2. 解压生成的 ZIP 文件，运行其中的 `work_assistant.py`

### 方法四：构建安卓版本

详细的安卓构建指南请查看 [ANDROID_BUILD.md](file:///workspace/android_app/ANDROID_BUILD.md)

**快速构建步骤：**

1. 进入安卓应用目录
```bash
cd android_app
```

2. 安装构建依赖
```bash
pip3 install buildozer kivy SpeechRecognition
```

3. 运行打包脚本
```bash
chmod +x build_apk.sh
./build_apk.sh
```

4. 构建成功后，APK 文件位于 `bin/` 目录

**环境要求：**
- Python 3.8+
- Java JDK 11+
- Android SDK（首次构建自动下载）
- 推荐系统：Ubuntu 20.04+/macOS 11+/Windows 10+

## 使用指南

### 专业开会模式（推荐）
1. 点击"🎯 开会模式"标签页
2. 输入**会议主题**和**参会人员**（可选）
3. **点击"开始会议"按钮** - 录音和计时同时开始
4. **正常说话开会** - 应用会自动：
   - 🎙️ 实时将语音转为文字
   - ✨ 自动修正错字和重复词
   - 📝 自动添加标点符号
   - 🎬 在字幕区实时显示
   - 🤖 智能分析关键词和行动项
5. **点击"结束会议"** - 停止录音和计时
6. **点击"生成总结"** - 生成完整的会议总结报告
7. **点击"保存会议"** - 保存到历史记录

### 查看会议历史
1. 点击"📚 会议历史"标签页
2. 查看所有历史会议记录
3. **单击**记录查看详情
4. **双击**记录可删除
5. 详情页包含"完整记录"和"智能总结"两个标签

### 智能总结报告
- 基本信息：主题、参会人员、时长、时间
- 核心关键词：自动提取的高频重要词汇
- 会议总结：AI生成的核心内容摘要
- 行动项列表：分类整理的待办事项

### 工作记录流程
1. 点击"📝 工作内容"标签页
2. 输入工作主题和日期
3. 详细描述工作内容
4. 点击"保存记录"按钮

### 设置会议提醒
1. 点击"⏰ 会议提醒"标签页
2. 输入会议主题和时间（格式：YYYY-MM-DD HH:MM）
3. 选择提前提醒时间
4. 点击"添加提醒"按钮
5. 应用会在设定时间自动弹窗提醒

### 查看记录详情
- 在任一记录列表中，单击记录项即可打开详情窗口
- 双击记录项可删除该记录（需确认）
- 会议记录详情包含"完整记录"和"智能总结"两个标签页

## 注意事项

1. **数据存储**: 所有数据保存在应用目录的 `data/` 文件夹中，请勿随意删除
2. **时间格式**: 会议提醒时间格式必须为 `YYYY-MM-DD HH:MM`
3. **提醒功能**: 应用需保持运行状态才能触发提醒
4. **数据备份**: 建议定期备份 `data/` 目录中的文件
5. **语音识别**: 需要安装 `SpeechRecognition` 和 `pyaudio` 库，确保麦克风正常工作
6. **网络要求**: 语音识别需要联网（使用Google云端API）
7. **录音环境**: 建议在安静环境下使用，提高识别准确率
8. **麦克风权限**: 首次使用需要授予麦克风权限
9. **文字纠错**: 自动纠错功能可减少常见错误，但无法保证100%准确
10. **实时字幕**: 字幕显示有轻微延迟属正常现象
